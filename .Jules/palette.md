## 2024-05-18 - CLI Discoverability
**Learning:** For CLI interfaces with more than 5-7 commands, always group the commands into functional categories (e.g., Processing, Validation, Generation, System) rather than presenting a flat list to improve discoverability. (Implemented in hl7v2-cli interactive mode)
**Action:** Apply command categorization when designing or extending CLI help menus or interactive modes.
