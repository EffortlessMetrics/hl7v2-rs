# v1.5.0 Release Graph Decision

Date: 2026-05-14

This decision selects the intended crates.io graph for the v1.5.0 publish
action. It is not a crates.io publish receipt, tag receipt, GitHub release
receipt, TestPyPI receipt, PyPI receipt, or npm receipt.

Post-release note: this decision was later fulfilled by
[`publish-v1.5.0-2026-05-15.md`](publish-v1.5.0-2026-05-15.md), which records
the crates.io upload, registry resolution, tag, GitHub release, and
Rust/CLI/server install-back proof. It still does not prove the public Python
`hl7v2` package on TestPyPI or PyPI.

## Decision

The v1.5.0 crates.io release graph is:

1. `hl7v2`
2. `hl7v2-python`
3. `hl7v2-server`
4. `hl7v2-cli`

`hl7v2`, `hl7v2-server`, and `hl7v2-cli` remain the primary Rust product graph.
`hl7v2-python` is included as a binding backend crate for the public Python
`hl7v2` package. It is not the recommended Rust API.

## Basis

The graph is selected because current `main` now has:

- the binding-backend ADR;
- binding-backend release-proof spec;
- publish-plan surface classification for `primary`, `bindings`, and
  `all-publishable`;
- binding backend dry-run tooling;
- publishable `hl7v2-python` metadata and README language;
- publish-surface classification guard;
- current-main dry-run refresh after #616-#618.

The current-main refresh passed at
`b4b7962e6f3f9d7ae5d91adf603e6328e3d13297` and is recorded in
[`publish-dry-run-v1.5.0-2026-05-14.md`](publish-dry-run-v1.5.0-2026-05-14.md).

## Boundaries

- This decision does not upload any crate to crates.io.
- This decision does not create a tag or GitHub release.
- This decision does not publish the public Python `hl7v2` package to
  TestPyPI or PyPI.
- This decision does not prove Python install-back.
- This decision does not create or publish an npm package.
- `hl7v2-python` remains binding infrastructure, not the Rust-user product API.
